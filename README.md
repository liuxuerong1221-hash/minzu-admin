# 铸牢中华民族共同体意识网站 - 后台管理系统

## 项目简介

这是一个基于 Vue 3 + Element Plus 开发的后台管理系统，采用红色主题风格（主题色：#A70101），用于管理"铸牢中华民族共同体意识"网站的各类内容。

## 技术栈

- **前端框架**: Vue 3
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **构建工具**: Vite
- **图表库**: ECharts
- **Mock数据**: MockJS
- **样式**: SCSS

## 功能模块

### ✅ 已完成功能

1. **用户登录系统**
   - 登录页面（红色渐变背景）
   - 用户认证
   - 路由守卫

2. **主布局框架**
   - 侧边栏菜单（支持折叠）
   - 顶部导航栏
   - 面包屑导航
   - 用户下拉菜单

3. **数据概览（Dashboard）**
   - 统计卡片（总访问量、文章总数、待审核、用户留言）
   - 访问趋势图表（ECharts）
   - 内容类型分布饼图
   - 热门文章 TOP10
   - 待处理事项
   - 快捷入口

4. **时政要闻管理**
   - 文章列表（搜索、筛选、分页）
   - 文章创建/编辑
   - 分类管理
   - 状态管理（草稿、待审核、已发布、已下线）
   - 置顶/推荐功能

5. **典型引领管理**
   - 人物列表（表格/卡片视图切换）
   - 人物档案创建/编辑（多标签页）
   - 基本信息、事迹材料、多媒体资源、荣誉档案
   - 推荐功能

### 🚧 待完善功能

- 文化传承管理
- 实践育人管理
- 交流互动管理
- 资源中心管理
- 审核工作流

## 主题色配置

系统采用红色系主题：

- 主色调：`#A70101`
- 浅色：`#C71818`
- 深色：`#8B0000`
- 渐变：`linear-gradient(135deg, #A70101 0%, #8B0000 100%)`

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境运行

```bash
npm run dev
```

访问地址：http://localhost:3000

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 开发规范

### 代码风格

- 使用 ES6+ 语法
- 组件命名采用 PascalCase
- 变量命名采用 camelCase
- 常量命名采用 UPPER_CASE

### 提交规范

- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 重构代码
- `test`: 测试相关
- `chore`: 构建/工具链相关

## 注意事项

1. 本项目为前端演示版本，使用 Mock 数据模拟后端接口
2. 实际生产环境需要对接真实后端 API
3. 富文本编辑器功能需要集成第三方库（如 TinyMCE、Quill）
4. 图片上传功能需要配置文件服务器
